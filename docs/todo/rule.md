# XRobot 跨平台重构项目 - Phase 执行规则

## 项目概述

本项目旨在将基于ESP32 IDF开发的xrobot智能机器人系统重构为跨平台架构，支持ESP32和Linux双平台运行。项目架构参考：<mcurl name="XiaoZhi ESP32 系统架构" url="https://deepwiki.com/78/xiaozhi-esp32"></mcurl>

## 核心执行规则

### 1. 主要节点完成验证规则

**每完成一个主要节点（如1.1、1.2等），必须执行以下验证流程：**

1. **编译验证**：执行 `idf.py build` 确保ESP32平台编译成功
2. **功能验证**：在ESP32硬件上测试相关功能正常
3. **代码质量检查**：确保代码符合项目标准
4. **文档更新**：更新相关技术文档和API说明
5. **Git提交**：提交节点完成的代码，并打上相应标签

### 2. 子任务完成验证规则

**每完成一个子任务（如1.1.1、1.1.2等），必须执行以下验证流程：**

1. **任务标记**：在对应的phase文档中标记子任务为已完成状态
2. **代码审查**：确保代码实现符合设计要求
3. **单元测试**：编写或更新相关的单元测试
4. **编译测试**：确保修改不会破坏现有编译
5. **提交记录**：提交代码并在commit信息中明确标注完成的子任务
